Leonida Ledger — the offline GTA VI trophy guide & tracker: all 55 official PS5 trophies with their names, descriptions and grades, a guide to each in our own words, saved progress with export and import, filters, a spoiler setting, a roadmap to the platinum, and the 7 missable trophies flagged. Static files, works with the network off.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```

The guide itself is `app/` — open `app/index.html` in a desktop browser and it works from its own files. `main.ts` hands the guide in for judging (`MAKEFUN_OUTPUT_DIR=out node main.ts`).

## Sources

Names, descriptions and grades are the official 55-trophy PlayStation 5 list, frozen 2026-11-18, as published by Exophase (https://www.exophase.com/game/grand-theft-auto-vi-psn/trophies/) and PSNProfiles (https://psnprofiles.com/trophies/43531-grand-theft-auto-vi) — verified against the live Exophase list on 2026-11-20. Count targets are PSN's progress targets. Every guide is written in our own words; where the official description does not pin down a trigger, the guide says so plainly.
